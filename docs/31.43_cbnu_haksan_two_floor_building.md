# 31.43 동일 평면을 사용하는 2층 건물

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 현재 1층 구조를 유지해 2층 건물로 확장.
- 실행 파일: [cbnu_haksan_2f_building.usda](../worlds/cbnu_haksan_2f_building/cbnu_haksan_2f_building.usda)
- 후속 변경: [31.44 2층 유리 출입문을 회색 벽으로 교체](31.44_cbnu_haksan_upper_entrance_wall.md). 아래 형상 개수는 최초 2층 생성 시점의 검증 기록이다.

## 구현

새 2층 Stage에서 기존 1층 Stage의 `/World`를 두 번 참조한다. 1층은 기존 prim 경로를 유지하고, 2층은 `/World/Floor_02`에 z=3.2m 이동을 적용한다. 양쪽 새 공간·조명, 동쪽 안쪽 직각 문, 가구, 디스플레이, 문, 동적 박스를 같은 XY 위치로 복제한다. 원본 1층 파일은 별도로 유지한다.

| 항목 | 높이 / 개수 |
| --- | --- |
| 1층 바닥 상단 | z=0m |
| 1층 천장 | z=3.0–3.1m |
| 2층 바닥 | z=3.1–3.2m |
| 2층 실내 | z=3.2–6.2m, 높이 3m |
| 2층 천장·지붕 | z=6.2–6.3m |
| 층간 벽 연결부 | z=3.0–3.2m, 22개 |
| 실내 패널 광원 | 각 층 18개, 총 36개 |
| 동적 택배 박스 | 각 층 16개, 총 32개 |

1층 천장 상단과 2층 바닥 하단은 z=3.1m에서 맞닿으며 두 슬래브의 부피가 겹치거나 사이에 틈이 생기지 않는다. 벽 위치를 따라 높이 0.2m의 회색 연결부와 collider를 추가했다. 2층 내부의 PhysicsScene·DomeLight·외부 보도 reference는 비활성화해 전역 물리 장면과 하늘 조명이 중복되거나 공중에 보도가 생기지 않게 했다.

층간 계단, 바닥 개구부, 작동하는 엘리베이터는 추가하지 않았다. 2층 로봇 시작점은 `/World/Floor_02/SpawnPoints/Spawn_South`, 월드 좌표 z=3.55m다.

## 파일과 함수

- [update_cbnu_haksan_two_floor.py](../scripts/update_cbnu_haksan_two_floor.py)의 `main()`: 원본 geometry의 층 높이·슬래브 두께와 Stage의 벽 좌표를 읽어 2층 Stage 및 연결부 생성. 생성 USD는 스크립트로 갱신한다.
- [test_two_floor_world.py](../scripts/test_two_floor_world.py)의 `main()`: 원본과 양쪽 층의 각 형상·재질 경로, 높이 차이, 조명·물리 장면 개수와 슬래브 접합 검사.
- [test_world_with_isaac_usd.sh](../scripts/test_world_with_isaac_usd.sh): 인자로 저장소 기준 테스트 스크립트 경로를 받을 수 있게 확장. 인자 없이 실행하면 기존 1층 테스트를 수행한다.
- [render_cbnu_haksan_two_floor_preview.py](../scripts/render_cbnu_haksan_two_floor_preview.py)의 `main()`: 실제 외곽 polygon·조명 좌표와 층간 높이를 사용하는 구조도 생성.
- [구조 미리보기](../worlds/cbnu_haksan_2f_building/preview_two_floor_structure.png): 천장을 생략한 구조 설명도이며 Isaac Sim GUI 렌더링은 아니다.
