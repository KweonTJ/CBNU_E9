# 31.57 양쪽 계단 3층 높이 연장·세로 창·계단실 천장 조명

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 2층 도착부 옆 펜스를 대신해 위로 올라가는 계단 설치. 양쪽 모두 3층 높이까지 연결. 확장된 계단실 벽에 세로 창 배치. 최종 조명 지시: 중간참 조명은 없애고 계단실 천장 조명 설치.
- 대상: [현재 Stage](../worlds/cbnu_haksan_2f_building/cbnu_haksan_2f_building.usda)
- 이전: [31.56 양쪽 계단](31.56_cbnu_haksan_staircases.md)

양쪽 계단의 기존 2층 막음 펜스 5개씩을 없애고, 같은 위치에서 출발하는 상부 계단을 추가했다. 2층 z=3.2m에서 z=4.8m의 중간참까지 오른 뒤 180° 돌아 z=6.4m 도착참에 연결된다. 3층 실내 전체가 아닌 계단과 도착참을 생성했다. 각 계단은 이제 총 36개 단차이며, 기존 단 높이 3.2/18m·디딤판 깊이 0.28m·폭 1.1m와 계단 아래 개방 구조를 유지한다.

도착참 크기는 2.5 × 1.2m이고 노출 가장자리에 난간을 배치했다. 2층 출발부는 계단으로 열려 있다. 상부 계단이 천장에 막히지 않도록 2층 천장에도 2.5 × 3.44m 개구부를 만들었다.

각 계단실 뒤벽 중앙에 폭 1m·높이 5m, z=0.6–5.6m의 연속된 세로 창을 하나씩 넣었다. 기존 Wall_18/22의 두 층 벽과 해당 층간 연결부는 표시·충돌을 끄고, 같은 외곽 범위의 벽 조각·금속 창틀·유리로 대체했다. 유리는 폭 0.91m·높이 4.91m·두께 0.025m이며 반투명 재질과 정적 충돌을 갖는다. 층간 연결부가 창 중앙을 가리지 않는다.

양쪽 LandingLight는 생성하지 않는다. 1층 CeilingLight_16/17은 비활성화 상태를 유지하고, 2층의 두 조명은 계단 입구 위 천장으로 옮겼다. 본체 중심은 왼쪽 (16.8892, 12.3903, 6.16), 오른쪽 (29.6224, 12.5544, 6.16)m이다. 3층 높이 도착참 아래에 있는 기존 천장에 배치해 열린 계단실과 상승 동선을 피한다. 세기는 8000, 아래쪽 조사 방향이며 활성 패널 조명은 1층 16개·2층 21개, 총 37개다. 복도 보강 조명은 유지했다.
