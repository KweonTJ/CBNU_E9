## 변경

[update_cbnu_haksan_two_floor.py](../scripts/update_cbnu_haksan_two_floor.py)의 `main()`에서 `/World/Floor_02/Architecture` 아래 다음 객체를 `active = false`로 처리했다.

- `DigitalDisplayWall_01`: 코너 디스플레이 전체(화면 9개, 본체·테두리·문자 포함).
- `ColumnDisplay_01`: 기둥 부착 디스플레이.
- `GrayPoster_01`, `GrayPoster_02`: 회색 전시 패널 및 L자 코너 패널.
- `GreenInformationBoard_01`–`03`: 안내판 3개와 각 안내판의 프레임·받침대.

1층 객체와 원본 1층 파일은 유지한다. 2층 건물 벽·기둥·목재 칸막이, 안내판 아래 공용 목재 단, 창문, 천장 조명도 유지한다. 앞서 제거한 2층 문·가구·택배·ATM은 비활성 상태를 유지한다.

[test_two_floor_world.py](../scripts/test_two_floor_world.py)의 `main()`에 위 7개 제거 경로를 추가했다. 해당 하위 객체가 활성 Stage에 남아 있지 않고 1층 형상이 원본과 같은지 검사한다. README에 현재 구성을 반영했다.
