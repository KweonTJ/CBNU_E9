# 31.28 CBNU 학산관 코너·기둥 소파 붉은 어두운 갈색 가죽 적용

- 수정일: 2026-09-04
- 신규 재질: `assets/materials/furniture/dark_reddish_brown_leather_material.usda`
- 대상 소파: `Sofa_Corner_01`, `Sofa_U_Column_02`

## 목적

남동쪽 코너 소파와 `Column_02`를 감싸는 U형 소파만 붉은 기가 도는 어두운 갈색 가죽으로 변경하고, 나머지 직선 소파 3개의 기존 갈색 가죽은 유지한다.

## 재질

- diffuse color: `(0.09, 0.055, 0.05)`
- specular color: `(0.18, 0.16, 0.15)`
- roughness: `0.38`
- clearcoat: `0.14`
- clearcoat roughness: `0.28`
- metallic: `0`

검정에 가까운 차콜 회색의 비중을 높이고 적갈색은 은은한 언더톤으로만 남겼다. 하이라이트도 중성 회색에 가깝게 낮춰 조명 아래에서 붉게 떠 보이지 않도록 했다.

## 적용 구조

- `Sofa_Corner_01/SofaUnified` → `SofaCorner/DarkReddishBrownLeather`
- `Sofa_U_Column_02/SofaUnified` → `SofaU/DarkReddishBrownLeather`
- `Sofa_02`, `Sofa_03`, `Sofa_05` → 기존 갈색 가죽 유지

소파의 형상, 위치, collision helper와 기둥 clearance는 변경하지 않았다. 통합 Mesh 재생성 스크립트도 동일한 material binding과 fallback color를 생성하도록 갱신했다.
