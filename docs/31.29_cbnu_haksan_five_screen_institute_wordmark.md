# 31.29 CBNU 학산관 5개 스크린 벽 연구원 명칭 적용

- 수정일: 2026-09-04
- 대상: `DigitalDisplayWall_01/SideSection`
- 표시 문구: `학연산공통기술연구원`

## 목적

기존 L자 전시벽 중 스크린 5개가 배치된 왼쪽 면의 상단 벽에 연구원 명칭을 추가한다. 3개 스크린 면과 기존 패널 구성은 변경하지 않는다.

## 구성

- 글자 영역: 가로 3.6m × 세로 0.38m
- 로컬 범위: y=0.25–3.85m, z=1.36–1.74m
- 월드 높이: 바닥에서 2.21–2.59m
- 스크린 구조 상단과의 간격: 0.14m
- 표현: 검정색 돌출 한글 Mesh
- 돌출 두께: 0.016m
- 충돌체: 없음

초기 투명 RGBA 데칼은 GUI 뷰포트에서 표시되지 않아 제거했다. Noto Sans CJK KR Bold 글꼴을 이진화한 뒤 475개의 세로 병합 run box로 변환해 하나의 `GlyphMesh`로 생성했다. 총 3,800개 점과 2,850개 quad face로 구성되며, 검정색 `UsdPreviewSurface`가 직접 binding된다.
