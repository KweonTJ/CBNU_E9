# 31.41 코너 디스플레이 바깥쪽 양쪽 공간

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 엘리베이터 코너로 가기 전 양쪽 회색·검정색 디스플레이 끝 벽에 빈 공간을 만든다. 최종 폭은 각 2.5m, 높이는 현재 건물 높이와 동일하다.
- 작업 범위: 사용자 지시에 따라 양쪽 공간만 먼저 수정. 2층 추가는 보류.

## 배치와 치수

로비에서 엘리베이터 방향을 기준으로 왼쪽 `GrayPoster_02`의 바깥쪽 끝과 오른쪽 `DigitalDisplayWall_01`의 바깥쪽 끝에 문 없는 공간을 만들었다. 디스플레이 쪽 경계를 고정하고 바깥쪽으로 폭을 확장했다. 깊이는 우선 2m로 설정한 구현값이다.

| 항목 | 왼쪽 공간 | 오른쪽 공간 |
| --- | --- | --- |
| 내부 폭 × 깊이 × 높이 | 2.5 × 2 × 3m | 2.5 × 2 × 3m |
| 내부 x 범위 | 15.6392–18.1392m | 28.3724–30.8724m |
| 내부 y 범위 | 13.0403–15.0403m | 13.2044–15.2044m |
| 입구 방향 | 로비 -Y 방향 | 로비 -Y 방향 |
| 추가 벽 | `Wall_15–18` | `Wall_19–22` |

입구는 폭 전체와 바닥에서 천장까지 3m 높이로 열려 있다. 기존 바닥과 천장을 공간 끝까지 확장하고 같은 재질을 사용한다. 측면·뒤쪽 벽과 바닥·천장은 정적 collision을 유지하며 입구와 내부에는 벽 collider가 없다. 디스플레이와 엘리베이터의 위치는 그대로다.

## 변경 파일과 함수

- [geometry.json](../worlds/cbnu_haksan_1f_corridor/config/geometry.json): `display_end_bays`에 치수·좌표·관련 장식·벽 이름 기록, 외곽 polygon 갱신.
- [기준 Stage](../worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda): `Wall_02`, `Wall_06`을 분할하고 `Wall_15–22` 추가. Floor·Ceiling의 꼭짓점·삼각형·바닥 UV 갱신.
- [test_world.py](../scripts/test_world.py): `validate_display_end_bays()`에서 두 공간의 실제 폭·깊이·높이, 장식 바깥쪽 배치, 벽 재질·collision, 전체 높이의 입구 통과 영역, 바닥·천장의 삼각형 방향과 표면 연결 검사.
- [validate_cbnu_haksan_detail.py](../scripts/validate_cbnu_haksan_detail.py): `validate_world()`의 벽 개수·분할 좌표와 polygon 검사 갱신.
- [render_cbnu_haksan_preview.py](../scripts/render_cbnu_haksan_preview.py): `main()`에서 두 공간의 치수와 확대 평면도 표시.
