# 31.53 꺾인 복도 코너 끝선으로 가벽 이동

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 남아 있는 꺾인 코너 끝까지 가벽 이동.
- 기준: 서쪽 복도 `Wall_08`과 `Wall_09`가 만나는 코너 벽선.
- 이전 변경: [31.52 에어컨 끝선 정렬](31.52_cbnu_haksan_partition_ac_edge.md)
- 결과: [2층 Stage](../worlds/cbnu_haksan_2f_building/cbnu_haksan_2f_building.usda) · [배치도](../worlds/cbnu_haksan_2f_building/preview_upper_partition.png)

가벽 중심 y를 9.05m에서 서쪽 복도 벽 `Wall_08`의 11.4103m까지 2.3603m 이동했다. 가벽의 북·남측 면이 기존 복도 벽 면과 일치하도록 두께를 맞추고, 기존 벽의 동쪽 끝에서 새 가벽이 바로 이어지게 했다. 동쪽 끝은 `Wall_01` 내측 면에 닿는다.

- 가벽 크기: 길이 19.2347m × 두께 0.2m × 높이 3m.
- 월드 범위: x=16.1145–35.3492m, y=11.3103–11.5103m, z=3.2–6.2m.
- 2층 `CeilingLight_12`, `13`, `14`는 가벽과 겹치지 않게 y=12m에서 12.25m로 0.25m 이동했다.
