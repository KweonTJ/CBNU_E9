# CBNU 학연산 코너형 디지털 전시벽 변경 기록

> 전시벽 부상 배치·좌우 길이 조정과 기둥 전방 이동은 [31.6 변경 기록](31.6_cbnu_haksan_display_wall_column_alignment.md)을 기준으로 한다.

- 수정 날짜: 2026-09-01 (Asia/Seoul)
- 기준 월드: `worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda`
- 목적: 참고 사진의 짙은 회색 코너형 전시·디지털 사이니지 구조물을 독립 asset으로 근사한다.

## 변경 내용

- `/World/Architecture/DigitalDisplayWall_01`을 추가했다.
- 배치는 북동쪽 로비/복도 분기 코너 `Wall_02`·`Wall_03` 안쪽 면이며, 위치는 `(25.9724, 13.2044, 0)`, yaw는 `0°`다.
- 전체 크기는 `4.5 × 2.5 × 2.35m`, 벽체 깊이는 `0.4m`다.
- 짙은 charcoal body와 밝은 ivory header를 각각 하나의 watertight L-footprint Mesh로 제작했다.
- 전면과 측면을 겹치는 render box로 만들지 않아 코너 중복 면을 제거했다.
- 전면 display 5개와 측면 display 3개를 배치했다.
- 각 display는 4면 black bezel과 bezel 전면보다 `0.009m` recessed된 dark blue low-emission screen으로 구성했다.
- collision은 render Mesh와 분리된 invisible box 2개로 근사했다. screen별 collision은 만들지 않았다.
- 위치와 yaw는 `architecture.json`에서 관리하고 `update_cbnu_haksan_architecture.py`로 layout을 재생성한다.
