# 31.45 2층 출입문 자리를 동일 규격 창문으로 변경

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 직전에 만든 2층 정면 벽을 양옆 창과 같은 크기의 창문으로 수정하고 창 간격 유지.
- 이전 변경: [31.44 출입문 벽](31.44_cbnu_haksan_upper_entrance_wall.md)
- 결과: [2층 Stage](../worlds/cbnu_haksan_2f_building/cbnu_haksan_2f_building.usda)

## 구현

[update_cbnu_haksan_two_floor.py](../scripts/update_cbnu_haksan_two_floor.py)의 `upper_entrance_window()`가 원본 왼쪽 창의 유리·프레임·하부 벽 형상을 읽고 같은 재질을 사용하는 가운데 고정창을 생성한다. `main()`에서 이전 `FrontEntranceInfillWall` 대신 `FrontEntranceGlassWalls/CenterFullHeightGlass`를 작성한다. 2층 출입문은 비활성 상태로 유지한다.

- 세 창의 유리 규격: 각각 폭 4.85m × 두께 0.025m × 높이 2.82m.
- 창 중심 x: 18.775m, 23.5m, 28.225m. 양쪽 중심 간격은 각각 4.725m.
- 기존 양옆 창과 문 양옆 기둥 위치를 유지한다. 유리판의 겹치는 가장자리는 불투명한 기존 기둥 내부에 완전히 들어간다. 외부로 노출되는 유리의 끝은 기둥에 가려지는 범위에 따라 달라진다.
- 유리 높이·두께·재질, 상하 프레임과 높이 1.02m 하부 벽은 원본 왼쪽 창과 같다.
- 1층 출입문 및 원본 1층 Stage는 유지한다. 기존 정면 Wall_10 collider를 사용한다.

[test_two_floor_world.py](../scripts/test_two_floor_world.py)는 세 유리판 규격·재질과 동일 중심 간격, 가장자리 겹침이 기둥 내부에 가려지는지, 원본 창·기둥 위치와 1층 문 보존을 검사한다. [구조도 스크립트](../scripts/render_cbnu_haksan_two_floor_preview.py) 및 README도 현재 창문 구성으로 갱신했다.
