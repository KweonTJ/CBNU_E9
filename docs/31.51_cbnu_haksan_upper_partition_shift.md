- 후속 변경: [31.52 에어컨 끝선 정렬 및 제거](31.52_cbnu_haksan_partition_ac_edge.md). 아래 수치는 1m 이동 당시의 기록이다.

## 변경

[update_cbnu_haksan_two_floor.py](../scripts/update_cbnu_haksan_two_floor.py)의 `main()`에서 2층 `CeilingLight_Central_Large` 전체를 비활성화해 등 본체·발광면·광원을 제거했다. 1층 대형등은 유지한다. 패널 광원은 총 35개(1층 18개, 2층 17개)다.

가벽 중심 y를 6.1739m에서 7.1739m로 이동했다. 이전 코너에서 떨어진 오른쪽 끝은 동쪽 `Wall_01` 내측 면까지 연장해, 기존 요청인 양 끝 벽 접합을 유지한다.

| 항목 | 현재 값 |
| --- | --- |
| 길이 × 두께 × 높이 | 19.2347 × 0.2 × 3m |
| x 범위 | 16.1145–35.3492m |
| y 범위 | 7.0739–7.2739m |
| 월드 z 범위 | 3.2–6.2m |
| 양 끝 접합 | 서쪽 Wall_09, 동쪽 Wall_01 |

기존 회색 재질과 충돌 설정을 유지한다. 이전에 0.6m 옮긴 소형등 위치는 그대로이며, 새로운 조명 이동은 없다. 1층 배치는 보존한다.

[test_two_floor_world.py](../scripts/test_two_floor_world.py)의 `main()`에 대형등 제거 예외를 추가하고 가벽 이동·양쪽 벽 접합 검사를 갱신했다. [구조도 스크립트](../scripts/render_cbnu_haksan_two_floor_preview.py)는 2층 대형등을 제외하고 새 가벽 위치와 이전 위치 점선을 표시한다. README도 갱신했다.
