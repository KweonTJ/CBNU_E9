# CBNU 학연산 기둥·통합 소파·ATM 변경 기록

> 메인 기둥과 서쪽 복도의 최신 치수·배치는 [31.4 변경 기록](31.4_cbnu_haksan_west_corridor_three_columns.md)을 기준으로 한다.

- 수정 날짜: 2026-09-01 (Asia/Seoul)
- 기준 월드: `worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda`
- 목적: 메인 기둥 단면을 `1.5m`로 줄이고 L/U형 소파를 단일 render Mesh로 재작성하며 코너 소파 옆 빈 벽면에 ATM을 추가한다.

## 변경 내용

- `assets/structural/column_2m.usda`
  - 호환용 파일명과 기존 reference는 유지했다.
  - `Body` 크기를 `1.5 × 1.5 × 3.0m`로 변경했다.
  - Column 1·2의 중심 위치는 변경하지 않았다.
- `assets/furniture/sofa_u_around_2m_column.usda`
  - 안쪽 접촉선을 `x = ±0.75m`, `y = -0.75m`로 옮겨 1.5m Column 2에 clearance 없이 맞췄다.
  - 위쪽이 열린 좌·하·우 U자 구조를 유지했다.
- `assets/furniture/sofa_corner.usda`, `sofa_u_around_2m_column.usda`
  - 보이는 geometry를 asset별 `SofaUnified` Mesh 하나로 통합했다.
  - base·seat·back 영역은 한 Mesh 안에서 겹치지 않고 경계에서 맞닿는다.
  - `subdivisionScheme = "none"`과 직접 만든 bevel ring을 사용했다.
  - 오목한 cap은 명시적으로 삼각화해 Hydra 자동 triangulation에 의한 면 깨짐을 제거했다.
  - 코너 소파 등받이의 좌석 쪽 돌출 return end를 삭제했다.
  - 기존 collision/helper primitive는 전부 invisible 상태로 유지했다.
- `worlds/cbnu_haksan_1f_corridor/config/furniture.json`
  - `ATM_02`를 코너 소파 긴 쪽 끝의 동쪽 빈 벽면 `(34.15, 6.5839, 0)`에 배치했다.
  - yaw `180°`로 화면과 조작부가 로비 안쪽을 향한다.
