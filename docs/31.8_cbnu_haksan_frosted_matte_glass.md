# CBNU 학연산 매트 유리 변경 기록

> 이후 유리를 다시 투명하게 복원하고 외부 보도블럭 광장을 추가한 상태는 `31.9_cbnu_haksan_clear_glass_exterior_pavers.md`를 기준으로 한다.

- 수정 날짜: 2026-09-02 (Asia/Seoul)
- 기준 월드: `worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda`
- 목적: 통유리 밖의 기본 그리드가 실내에서 선명하게 보이지 않도록 활성 유리를 반투명 매트 마감으로 변경한다.

## 변경 내용

다음 활성 유리 asset의 `UsdPreviewSurface`를 같은 값으로 통일했다.

- `assets/architecture/windows/front_entrance_glass_walls.usda`
- `assets/architecture/windows/north_corridor_end_glass_wall.usda`
- `assets/architecture/doors/glass_door_double.usda`
- `assets/architecture/doors/glass_door_double_pair.usda`

| 속성 | 변경 값 |
| --- | --- |
| diffuseColor | `(0.70, 0.76, 0.77)` |
| opacity | `0.82` |
| roughness | `0.72` |
| opacityThreshold | `0` 유지 |
| finish metadata | `frosted matte privacy glass` |

기존 `opacity 0.13~0.16`, `roughness 0.08`의 맑은 유리는 외부 그리드를 거의 그대로 노출했다. 새 설정은 밝은 중성색과 높은 불투명도·거칠기를 사용해 유리 형태와 약한 투과감은 남기면서 외부 그리드를 대부분 차폐한다.

## 유지 사항

- 모든 유리 panel 크기와 위치는 변경하지 않았다.
- 유리문 frame, handle, leaf 수와 두 출입문 사이 간격은 유지했다.
- `Wall_10`, `Wall_04`의 기존 collision은 유지했다.
- 유리 render prim에는 별도 collision을 추가하지 않았다.
- 서쪽 복도 끝 `Wall_07`은 기존처럼 불투명 벽이다.

## 정문 접합부 빈틈 마감

- 왼쪽 외벽 안쪽 면과 통유리 outer frame 사이 `0.1355m` 빈 구간을 frame 확장으로 채웠다.
- 양쪽 entrance pillar와 통유리 door-side frame 사이 각각 `0.12m` 빈 구간을 frame 확장으로 채웠다.
- 두 양개 유리문 세트 사이 중앙 고정 유리를 `0.42m → 0.44m`로 넓혀 `0.44m` 간격을 정확히 채웠다.
- 각 문짝 유리는 기존 상·하단 rail 사이에 남던 `0.05m / 0.02m` 빈 구간을 없애도록 `0.67 × 1.83m`로 확장했다.
- 중앙 고정 유리는 세로를 `2.10m → 2.22m`로 확장해 상부 transom의 glass 시작선까지 연결했다.
- 통유리 panel, 출입문, 기둥 위치는 변경하지 않았다.
- 상부 transom은 기존처럼 문 외곽 `4.16m` 폭과 천장 높이까지 연속된다.
