# CBNU 학연산 실내 천장·통유리·통합 소파 변경 기록

> 서쪽 복도 끝 벽과 메인 3기둥의 최신 상태는 [31.4 변경 기록](31.4_cbnu_haksan_west_corridor_three_columns.md)을 기준으로 한다.

- 수정 날짜: 2026-09-01 (Asia/Seoul)
- 저장소: `CBNU_E9`
- 기준 월드: `worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda`
- 변경 목적: 기존 복도 외곽과 collider를 유지하면서 실내 천장, 조명, 통유리 벽과 L/U형 소파 접합부를 정리한다.

## 천장과 조명

- 복도 polygon과 동일한 닫힌 천장 Mesh를 추가했다.
- 천장 아래 면은 `z = 3.0m`, 두께는 `0.10m`다.
- warm white 무광 material과 collision을 적용했다.
- 일반 매입형 LED panel 12개를 배치했다.
- 중앙에 `6.0 × 2.4m` 대형 RectLight panel 1개를 추가했다.
- 어두운 실내 GUI 피드백을 반영해 일반 panel intensity를 `8000`, 대형 panel을 `12000`으로 높였다.
- 대형 panel은 넓은 면적 때문에 출력이 약해지지 않도록 `normalize = false`, DomeLight는 `1600`으로 설정했다.
- 위치와 yaw는 `config/ceiling.json`, 생성 결과는 `config/ceiling_layout.usda`에서 관리한다.

## 통유리 벽

- 남쪽 유리 출입문 좌우에 각 `4.85 × 2.82m` 통유리를 배치했다.
- 서쪽 직선 복도 끝에 `1.655 × 2.82m` 통유리 1장을 배치했다.
- 북쪽 세로 복도 끝에 `3.1332 × 2.82m` 통유리 1장을 배치했다.
- 새 유리는 시각용이며 collision을 추가하지 않는다.
- 기존 `Wall_10`, `Wall_07`, `Wall_04`는 불투명 시각만 숨기고 원래 치수와 collision을 유지했다.

## L/U형 소파

- visible plush primitive 방식은 폐기했다.
- 두 asset에서 실제 visible geometry는 각각 `SofaUnified` Mesh 하나만 사용한다.
- 한 Mesh 안에서 base·seat·back topology가 겹치지 않고 경계에서 맞닿는다.
- 직접 만든 bevel ring으로 좌석과 등받이 윤곽을 유지하며 subdivision은 사용하지 않는다.
- 오목한 L/U cap은 명시적인 triangle face로 생성해 Hydra의 n-gon 자동 분할로 면이 깨지는 문제를 막았다.
- 모든 Cube/Capsule/Sphere/Cylinder helper, button과 foot은 `visibility = "invisible"`이다.
- Corner back의 좌석 쪽으로 튀어나오던 return end를 제거하고 둥근 L자 접합부까지만 이어지게 했다.
- U형은 local `+Y`가 열린 구조와 `columnClearance = 0`을 유지한다.
- render Mesh에는 collision API를 적용하지 않고 기존 invisible proxy만 유지한다.
- 기존 brown sofa material reference를 그대로 사용한다.

## 정면 출입구 기둥

- ATM을 감싸는 배치가 아니라 정면 출입구의 양쪽 경계에 배치했다.
- 왼쪽 기둥은 ATM collision 오른쪽 끝 `x=20.3775`와 문 frame 왼쪽 끝 `x=21.42` 사이를 정확히 채운다.
- 기둥 폭은 빈 공간과 같은 `1.0425m`, 깊이 `1.0m`, 높이 `3.0m`다.
- 뒤쪽 면은 남쪽 벽선에 유지하고 실내 방향으로 크게 돌출시켰다.
- 오른쪽 기둥은 출입구 중심 `x=23.5`를 기준으로 동일 크기·동일 거리로 대칭 배치했다.
- 기존 남쪽 벽 collider가 있으므로 두 기둥은 decorative, collision disabled로 유지한다.
- 두 양개문 세트 사이 `0.44m` 빈 공간에는 폭 `0.42m`, 높이 `2.10m` 고정 유리 panel을 추가했다.
- 문 header `z=2.20m`와 천장 `z=3.0m` 사이에는 `4.16 × 0.72m` 고정 유리 transom과 상·하부 금속 rail을 추가했다.
