# 31.50 2층 코너에서 뒤편 벽까지 가벽 설치

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 사진 오른쪽 코너에서 반대편 벽까지, 현재 층 높이와 같은 가벽 생성. 방향 확인에 대한 사용자 답변: `뒤까지`.
- 실행 파일: [2층 Stage](../worlds/cbnu_haksan_2f_building/cbnu_haksan_2f_building.usda)
- 배치: [가벽 평면도](../worlds/cbnu_haksan_2f_building/preview_upper_partition.png)
- 후속 변경: [31.51 엘리베이터 쪽으로 1m 이동](31.51_cbnu_haksan_upper_partition_shift.md). 아래 치수는 최초 설치 시점이며 평면도는 최신 배치를 표시한다.

## 구현

사진 오른쪽 코너를 남동쪽 `Wall_11/Wall_12` 접합부로 해석해 `Wall_12` 벽선을 서쪽 `Wall_09` 내측 면까지 직선으로 연장했다. 2층 `/World/Floor_02/Environment/PartitionWall_01`에 회색 가벽과 정적 충돌 형상을 추가했다.

| 항목 | 값 |
| --- | --- |
| 길이 × 두께 × 높이 | 14.5391 × 0.2 × 3m |
| 양 끝 x | 16.1145–30.6536m |
| 벽 중심 y | 6.1739m |
| 월드 높이 z | 3.2–6.2m |
| 재질 | 2층 `WallColumnLightGray` |

가벽은 양쪽 기존 벽 면과 맞닿으며 바닥부터 천장까지 연결된다. 별도 출입구는 만들지 않았다. 겹치던 2층 `CeilingLight_15`만 y=6.0m에서 5.4m로 0.6m 이동해 조명 본체가 벽을 관통하지 않게 했다. 1층과 다른 2층 형상은 보존했다.

- [update_cbnu_haksan_two_floor.py](../scripts/update_cbnu_haksan_two_floor.py)의 `main()`: 기존 벽 위치·두께로 가벽 길이·위치 계산, 2층 가벽 및 조명 위치 override 생성.
- [test_two_floor_world.py](../scripts/test_two_floor_world.py)의 `main()`: 접합부·바닥·천장 높이·재질·충돌, 조명 간섭, 1층 보존 검사.
- [render_cbnu_haksan_two_floor_preview.py](../scripts/render_cbnu_haksan_two_floor_preview.py)의 `main()`: 생성 USD의 가벽 좌표를 읽어 구조도와 평면도 생성.
