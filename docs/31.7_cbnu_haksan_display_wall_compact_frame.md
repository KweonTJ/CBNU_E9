# CBNU 학연산 전시벽 compact frame 변경 기록

- 수정 날짜: 2026-09-01 (Asia/Seoul)
- 기준 월드: `worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda`
- 목적: 흰색 상부 구조를 제거하고 전시벽의 세로 비율·검정 배경·베젤·벽면 돌출을 줄인 뒤 전체를 더 높게 배치한다.

## 변경 내용

- `Header`, `HeaderUnified`, sign bar와 흰색 header material을 제거했다.
- display 외곽 크기는 가로 `0.62m`를 유지하고 세로를 `1.40m → 0.98m`로 줄였다.
- 왼쪽 5개와 오른쪽 3개는 동일한 `digital_display_panel.usda`를 scale 없이 공유한다.
- 각 display의 검정 bezel 폭은 `0.04m → 0.02m`로 줄였다.
- 내부 screen은 `0.58 × 0.94m`로 넓혔으며 bezel 전면보다 `0.009m` recessed 상태를 유지했다.
- section 외곽 trim은 `0.04m` 두께로 줄였다.
- 차콜 L자 `MainBody` 높이를 `1.78m → 1.22m`로 줄여 화면 위·아래 검정 배경 여백을 축소했다.
- 월드 root Z와 실제 floor clearance를 `0.85m`로 올렸다. 최종 상단 높이는 `2.07m`다.
- 벽면 돌출 깊이는 `0.40m → 0.30m`로 줄였다.
- render body와 분리된 두 invisible collision box도 `0.30m` 깊이와 `1.22m` 높이에 맞췄다.

## 유지 사항

- 긴 왼쪽 `4.5m / 5개`, 짧은 오른쪽 `2.5m / 3개` 구성을 유지했다.
- 차콜 본체는 하나의 watertight L-footprint Mesh다.
- 화면의 low-emission material과 recessed 구조를 유지했다.
- 기존 복도, 문, 소파, 바닥 geometry는 이번 수정에서 변경하지 않았다.
