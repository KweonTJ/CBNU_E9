# CBNU 학연산 로비 가구·출입구 후속 변경 기록

- 수정 날짜: 2026-09-01 (Asia/Seoul)
- 기준 월드: `worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda`
- 변경 목적: 복도·기둥 geometry를 유지하면서 소파 접합부, ATM, 테이블과 정면 유리 출입구를 보완한다.

## 변경 내용

- `assets/furniture/sofa_corner.usda`, `sofa_u_around_2m_column.usda`
  - 겹쳐 보이던 capsule·sphere plush overlay를 숨겼다.
  - 보이는 seat/back을 각각 하나의 `catmullClark` 통합 Mesh로 구성해 꺾임부의 중복 끝 캡을 제거했다.
  - U형 root 위치, open top, Column 2 접촉과 외곽 footprint는 유지했다.
- `assets/equipment/atm_machine.usda`
  - 기존 `Sofa_04` 위치에 둘 실내 은행 ATM을 추가했다.
  - 본체, header, 발광 screen, keypad, card/receipt/cash slot을 포함한다.
- `assets/furniture/lobby_table.usda`
  - sofa 기본 폭 `2.0 m`에 맞춰 X scale로 길이를 조정할 수 있는 목재 로비 테이블을 추가했다.
  - 요청에 따라 평면 깊이를 `0.68 m`에서 `1.36 m`로 2배 늘렸다.
- `config/furniture.json`
  - `Sofa_04`를 제거하고 같은 위치에 `ATM_01`을 배치했다.
  - `Sofa_03` 앞 `Table_01`, `Sofa_05` 앞 `Table_02`를 추가했다.
  - table width scale은 각각 paired sofa와 동일한 `1.4203`, `1.6087`이다. 실제 폭은 `2.8406 m`, `3.2174 m`다.
  - 깊이 증가 후 sofa 쪽 모서리 간격을 유지하기 위해 table 중심 Y를 `1.74 m`로 옮겼다.
  - 최초에는 사진 위치를 반대로 식별해 동쪽 `Sofa_02`를 바꿨으나 이를 복구했다. 실제 사진 위치인 서쪽 `Door_Double_01/02` 사이의 `Sofa_01`을 제거하고 같은 중심 `[16.4245, 6.3188, 0]`, yaw `90°`, 같은 평면 크기 `1.6232 × 0.82 m`의 `Table_03`으로 교체했다.
  - `Table_03`은 전용 `lobby_table_filled.usda`를 사용한다. 상판 아래에는 폭 `1.82`, 깊이 `1.20`, 높이 `0.54 m`의 목재 하부를 두며 instance scale 적용 후 기존 footprint 안에서 바닥부터 apron까지 빈 공간 없이 채운다.
  - 후속 요청으로 `Table_01/02`도 같은 filled-base asset으로 변경했다. 두 책상의 위치·paired sofa 폭·깊이 `1.36 m`는 유지했다.
- `assets/architecture/doors/glass_door_double.usda`
  - 투명 glass panel 2개, 금속 frame과 pull handle을 가진 정적 양개 유리문을 추가했다.
- `assets/architecture/doors/glass_door_double_pair.usda`
  - 유리 양개문 asset 2개를 좌우로 배치해 총 4개의 투명 door leaf를 구성했다.
  - 두 양개문 세트의 중심은 `x = ±1.15 m`이며 frame 사이에 `0.44 m` 간격을 둔다.
- `config/doors.json`
  - 남쪽 정면의 `Door_Double_05`를 `double_glass_pair`로 변경했다. root 위치 `[23.5, 0.17, 0]`, yaw `0°`는 유지했다.
- 생성기·preview·validator와 `README_CBNU_HAKSAN.md`를 최신 asset 유형과 수량에 맞춰 갱신했다.
