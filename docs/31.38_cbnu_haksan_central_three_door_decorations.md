# 31.38 CBNU 학산관 중앙 문 3개 동일형 목재 포털

- 수정일: 2026-09-04 (Asia/Seoul)
- 대상: `/World/Doors/Door_Double_01`, `/World/Doors/Door_Double_02`, `/World/Doors/Door_Single_04`

## 목적

좁은 서쪽 복도와 정문 유리문을 제외한 중앙부 문 3개에 동쪽 흰색 양개문과 같은 단순한 목재 포털을 추가한다. 최초의 화려한 pilaster·rosette·2단 crown 안은 폐기했다.

| 문 | 위치 | 방향 | 장식 외곽 크기 |

기존 갈색 문짝·패널·손잡이와 배치 좌표는 유지하고 장식만 합성한다.

## 포털 구성

- 동쪽 문과 같은 honey-brown `(0.52, 0.27, 0.09)` 재질
- 좌측 `LeftPortalJamb`, 우측 `RightPortalJamb`
- 상부 `PortalHeader`
- 좌우 jamb 안쪽 면과 상부 header 하단이 문짝 외곽에 직접 맞닿아 여백 `0m`
- plinth·capital·rosette·crown·중앙 장식 없음
- 포털은 시각용이며 기존 벽 collision을 재사용
