# 31.40 동쪽 벽 직선 연장과 안쪽 직각 출입문

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 기존 문이 붙은 벽을 안쪽으로 곧게 연장하고 그 끝에 새 직각 문 하나를 배치. 공간 폭은 문틀 너비 2.08m, 깊이는 1m. 사용자가 해당 배치를 확인했다.
- 대상: `Wall_02` 동쪽 부분, 기존 `Door_Double_03` 왼쪽.

## 변경

새 `Door_Double_06`은 1m 안쪽 공간의 끝에 있다. 기존 `Door_Double_03`이 붙은 동쪽 `Wall_01`을 같은 x 좌표로 곧게 연장해 새 문의 오른쪽 문틀까지 이어지게 했다. 벽이 중간에서 옆으로 꺾이는 단차가 없다. 반대쪽 `Wall_13`과 뒤쪽 `Wall_14`, 확장 바닥·천장에 collision을 적용했다. 문은 닫힌 정적 표현이며 별도 방 내부나 개폐 동작은 구현하지 않았다.

| 구성 | 위치 / 치수 |
| --- | --- |
| 공간·문틀 폭 | 2.08m, x=33.2692–35.3492m |
| 공간 깊이 | 기존 벽 실내면 y=13.2044m부터 뒤쪽 벽 실내면 y=14.2044m까지 1m |
| 곧게 이어지는 동쪽 벽 | 중심 x=35.4492m, 실내면 x=35.3492m |
| 새 정면 문 `Door_Double_06` | (34.3092, 14.1769, 0), yaw 0°, -Y 방향 |
| 기존 오른쪽 문 `Door_Double_03` | (35.32, 12.3, 0), yaw 90°, 새 문과 직각 |
| 문 장식 | 기존 흰색 양개문 + 2.08 × 0.20 × 2.28m 목재 포털 |

새 문은 문짝 뒤의 `Wall_14` collider를 사용한다. 입구와 문 앞 공간에는 벽 collider가 남지 않도록 `Wall_02`를 줄였다. 기존 가구와 기존 출입문 좌표는 유지했다.

- [doors.json](../worlds/cbnu_haksan_1f_corridor/config/doors.json): 새 문 좌표와 방향. 기존 생성 스크립트로 `doors_layout.usda` 재생성.
- [기준 Stage](../worlds/cbnu_haksan_1f_corridor/cbnu_haksan_1f_corridor.usda), [geometry.json](../worlds/cbnu_haksan_1f_corridor/config/geometry.json): 동쪽 벽 직선 연장, 좌측·뒤쪽 벽 및 바닥·천장 footprint, 삼각형 면과 바닥 UV 반영.
- [test_world.py](../scripts/test_world.py): `validate_east_adjacent_doors()`에서 동쪽 벽의 직선 연장, 문틀과 좌우 벽 접합, 폭·깊이·직교성, 입구 collision 및 바닥·천장의 삼각형 방향과 연결 확인.
- [validate_cbnu_haksan_detail.py](../scripts/validate_cbnu_haksan_detail.py): `validate_world()`, `validate_ceiling()`, `validate_doors()`의 footprint·벽·문 개수 반영.
- [render_cbnu_haksan_preview.py](../scripts/render_cbnu_haksan_preview.py): `main()`에서 실제 문 번호와 코너 확대 평면도 표시.
