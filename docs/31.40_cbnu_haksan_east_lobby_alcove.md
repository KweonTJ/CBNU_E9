# 31.40 동쪽 코너의 인접한 직각 출입문

- 수정일: 2026-09-18 (Asia/Seoul)
- 요청: 새 문 하나를 기존 오른쪽 문 바로 옆에 배치. 두 문은 직각이며 중간에 꺾여 들어가는 공간을 두지 않는다.
- 대상: `Wall_02` 동쪽 부분, 기존 `Door_Double_03` 왼쪽.

## 변경

`Wall_02`의 새 `Door_Double_06`을 기존 `Door_Double_03` 바로 옆 코너로 옮겼다. 두 목재 문틀은 틈 없이 직각으로 맞닿는다. 벽·바닥·천장은 원래 외곽선을 사용하며 별도 후퇴 공간과 추가 조명은 없다. 문은 닫힌 정적 표현이며 별도 방 내부나 개폐 동작은 구현하지 않았다.

| 구성 | 위치 / 치수 |
| --- | --- |
| 새 문틀 폭 | 2.08m, x=33.14–35.22m |
| 두 문틀 접합 | 새 문 오른쪽 끝과 기존 문 실내측 면이 x=35.22m에서 접촉 |
| 새 정면 문 `Door_Double_06` | (34.18, 13.1769, 0), yaw 0°, -Y 방향 |
| 기존 오른쪽 문 `Door_Double_03` | (35.32, 12.3, 0), yaw 90°, 새 문과 직각 |
| 문 장식 | 기존 흰색 양개문 + 2.08 × 0.20 × 2.28m 목재 포털 |

새 문은 문짝 뒤의 기존 `Wall_02` collider를 사용한다. 기존 가구와 기존 출입문 좌표는 유지했다.

## 변경 파일과 이유

- [doors.json](../worlds/cbnu_haksan_1f_corridor/config/doors.json): 새 문 좌표와 방향. 기존 생성 스크립트로 `doors_layout.usda` 재생성.
- [test_world.py](../scripts/test_world.py): `validate_east_adjacent_doors()`에서 두 문 방향의 직교성, 문틀 접촉과 겹침 여부, 기존 벽 실내면과 문짝 접합, collision, 추가 연결 벽·문·조명의 부재를 확인.
- [validate_cbnu_haksan_detail.py](../scripts/validate_cbnu_haksan_detail.py): `validate_doors()`의 문·포털 개수 반영.
- [render_cbnu_haksan_preview.py](../scripts/render_cbnu_haksan_preview.py): `main()`에서 실제 문 번호와 코너 확대 평면도 표시.
